# Velocity - POOL N Gym

A premium fitness club landing page with intro animation and modern dark theme design.

## Features

- **Intro Animation**: Autoplay video that smoothly transitions to main content
- **Dark Luxury Theme**: Black background with neon blue accents
- **Hero Section**: Bold branding with animated gradient effects
- **Feature Sections**: Swimming pool and gym showcases with scroll animations
- **Responsive Design**: Optimized for all devices
- **Smooth Animations**: Parallax effects, fade-ins, and micro-interactions

## Files Structure

```
Velocity/
├── index.html          # Main HTML structure
├── styles.css          # Complete styling with animations
├── script.js           # JavaScript for animations and interactions
├── download (1).mp4    # Intro animation video
├── swimming pool.jpeg  # Swimming pool feature image
├── gym.jpeg           # Gym feature image
└── README.md          # This file
```

## Getting Started

1. **Local Development**: Open `index.html` in your browser or use a local server
2. **Video Requirements**: Ensure the intro video is in MP4 format for best compatibility
3. **Images**: Replace placeholder images with high-quality photos for best results

## Technical Details

- **Fonts**: Oswald (headers) and Inter (body) from Google Fonts
- **Animations**: CSS keyframes and JavaScript Intersection Observer
- **Layout**: CSS Grid and Flexbox for responsive design
- **Color Scheme**: Black (#000) background with neon blue (#00d4ff) accents

## Browser Compatibility

- Chrome/Chromium: Full support
- Firefox: Full support  
- Safari: Full support
- Edge: Full support

## Customization

- Edit colors in `styles.css` (main accent: `#00d4ff`)
- Modify animation timings in `script.js`
- Update content directly in `index.html`
- Add new sections by following the existing feature section pattern
